DRIVECLUB Split Screen 0.1.0

Original mod by nuvsyakoetakoe.
Copyright © 2026 nuvsyakoetakoe.

Race on one PC with two players. Player 1 uses the upper screen and player 2
uses the lower screen. Each player chooses a car.

Requirements

Windows x64, DRIVECLUB port 0.4.2, and an installed copy of CUSA00003 with
game update 1.28. On a fresh installation, complete the initial setup and
start a normal race once.

Installation

1. Close the game and its launcher.
2. Extract the ZIP to a separate folder. Keep the installer for removal.
3. Open SplitScreen-Setup.exe, click Install, and select DriveClub.exe in
   your port installation. Setup backs up the original launcher.
4. After setup confirms installation, start the game through DriveClub.exe.

Language

Setup opens in English. Select Русский in the language list for Russian.
In the game, Split Screen uses Russian when the launcher’s game language is
Russian and English for every other selection. You can change the game
language between launches without reinstalling. The game's own screens
continue to use the selected game language.

First race

Open Drive → Split Screen. In Split Screen settings, choose the player
names, input devices and keyboard bindings. A keyboard and a gamepad can
be used together. Select Race, choose the country, track, weather and event
settings, then select Play. Player 1 chooses a car first, followed by player 2.

Removal

Close the game and launcher. Open SplitScreen-Setup.exe, click Uninstall
and select the same DriveClub.exe. Setup restores the original launcher.
Your saves and Split Screen player settings are kept.
